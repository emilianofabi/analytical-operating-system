# Changelog

All notable changes to the Analytical Operating System curriculum are documented here.

This project follows semantic versioning:

- MAJOR version: structural curriculum redesign.
- MINOR version: new modules, rubrics, templates, or pathways.
- PATCH version: typo fixes, formatting cleanup, minor clarifications.

## v0.2.0 - Curriculum Infrastructure Expansion

### Added

- Module index.
- Dependency graph.
- Rubric index.
- Assumption-awareness rubric.
- Causal reasoning quality rubric.
- Cross-module synthesis protocol.
- Governance folder.
- Ops folder for scripts.

### Changed

- Operational scripts moved out of root and into /ops.
- Curriculum architecture now separates content, module cards, rubrics, templates, artifacts, and operational scripts.
