\# Analytical Operating System Curriculum



This repository contains the curriculum architecture for \*\*Toward an Analytical Operating System\*\*.



The project is designed to be used with Hermes through the `curriculum-orchestrator` skill.



\## Core Principle



This curriculum cultivates analytical judgment across economics, statistics, causal inference, machine learning, AI systems, data engineering, policy, ethics, entrepreneurship, and capstone synthesis.



\## Governing Commitments



1\. Purpose before technique.

2\. Identification before estimation.

3\. Model as controlled omission.

4\. Data is produced, not found.

5\. Metrics are proxies, not values.

6\. Prediction is not explanation.

7\. Infrastructure is epistemic.

8\. Systems are sociotechnical.

9\. Responsible design requires governance.

10\. Synthesis requires visible artifacts.



\## Folder Structure



\- `curriculum/` — master curriculum documents.

\- `modules/` — structured module cards.

\- `skills/` — reusable Hermes workflow specifications.

\- `rubrics/` — assessment rubrics.

\- `templates/` — lesson, capstone, review, and portfolio templates.

\- `learner-state/` — progress and artifact memory.

\- `artifacts/` — student-produced work.

\- `evaluations/` — scored artifacts, calibration notes, and defense records.
