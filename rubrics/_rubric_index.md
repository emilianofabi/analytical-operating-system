# Rubric Index

This file defines the assessment architecture for the Analytical Operating System curriculum.

Rubrics are aligned to competencies, modules, and artifact types.

## Core Rubrics

| Rubric File | Competency | Primary Use |
|---|---|---|
| assumption_awareness.md | Model Construction and Assumption Analysis | Technical reports, models, notebooks, capstones |
| causal_reasoning_quality.md | Causal Identification and Counterfactual Reasoning | Causal memos, experiments, policy evaluation |
| institutional_analysis_depth.md | Institutional, Market, and Policy Judgment | Policy memos, market analyses, governance proposals |
| responsible_system_design.md | Responsible Sociotechnical System Design | AI audits, model cards, deployment reviews |
| technical_artifact_quality.md | Epistemic Infrastructure and Computational Formalization | Code, pipelines, repositories, data systems |
| synthesis_portfolio_quality.md | Synthesis and Intellectual Production | Capstones, portfolios, final projects |

## Standard 4-Point Scale

1. Emerging
2. Developing
3. Proficient
4. Advanced

## Universal Evidence Requirements

Every rubric-based assessment should identify:

1. artifact claim;
2. method;
3. evidence;
4. assumptions;
5. limitations;
6. domain context;
7. revision priorities.

## Calibration Protocol

Before formal scoring, reviewers should:

1. read the artifact independently;
2. assign preliminary rubric scores;
3. cite evidence for each score;
4. compare scoring rationales;
5. resolve descriptor ambiguity;
6. document final score and rationale;
7. preserve anonymized exemplars for future calibration.
