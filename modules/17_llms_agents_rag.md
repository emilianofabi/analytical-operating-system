# Module 17: Large Language Models, AI Agents, Retrieval Systems, and Human-AI Interaction

## Track
Methods & Systems

## Credit Hours
5

## Core Purpose

Cultivate AI systems judgment: the ability to design, evaluate, and govern systems built around foundation models, prompts, retrieval, tools, memory, agents, workflows, and human oversight.

## Governing Principles

1. LLMs are components inside larger systems.
2. Prompts are context design, not incantations.
3. Retrieval is knowledge infrastructure.
4. Tool use turns language generation into action.
5. Agents are fragile sequential decision systems.
6. Evaluation is central, not optional.
7. Human-AI interaction is delegation design.
8. Fluency is not truth.

## Core Questions

- What task does the system perform?
- What information is available in context?
- What should be retrieved?
- When should a tool be called?
- What actions require human confirmation?
- What errors matter?
- How is output evaluated?
- How does the interface shape trust and control?
- What should be logged and monitored?
- When is an LLM system inappropriate?

## Lesson 1

### Title
LLMs as Components Inside Systems

### Central Problem
A language model alone is not a complete AI product. Useful AI systems combine models with instructions, retrieval, tools, interfaces, memory, evaluation, governance, and human oversight. The central design problem is how to make probabilistic language behavior useful, grounded, safe, and inspectable.

### Required Concepts

- language model
- context
- prompt
- retrieval
- tool use
- grounding
- hallucination
- evaluation
- human oversight
- system boundary

### Required Outputs

- system map for an LLM application
- short memo distinguishing model capability from system reliability
- oral-defense answer explaining why fluent output is not sufficient evidence
