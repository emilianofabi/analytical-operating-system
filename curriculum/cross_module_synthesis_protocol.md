# Cross-Module Synthesis Protocol

This file defines how modules should be combined into interdisciplinary projects and capstones.

## Governing Principle

Synthesis is not accumulation. A multi-module project must specify what each module contributes and why the project would be weaker without it.

## Required Synthesis Fields

Every cross-module project must define:

1. central question;
2. primary claim;
3. audience;
4. primary module;
5. secondary modules;
6. role of each module;
7. method;
8. evidence;
9. artifact;
10. assumptions;
11. ethical or institutional implications;
12. assessment rubrics.

## Canonical Project Archetypes

# Archetype 1: Causal Product Analytics

## Module Combination

- 03 Causal Inference
- 20 Experimental Design and Metrics
- 07 Data Engineering and Infrastructure
- 19 Data Visualization and EDA
- 14 Decision Theory and Optimization

## Central Question

Did a product, policy, model, or feature change a meaningful outcome?

## Required Artifacts

- metric definition sheet;
- experiment or quasi-experiment design;
- data pipeline or instrumentation plan;
- analysis notebook;
- decision memo;
- limitation statement.

## Assessment Rubrics

- causal_reasoning_quality;
- assumption_awareness;
- technical_artifact_quality.

How can reliable data or AI infrastructure transform messy inputs into trustworthy knowledge and decisions?

## Required Artifacts

- incident analysis;
- documentation.

## Assessment Rubrics

- technical_artifact_quality;
- assumption_awareness;
- responsible_system_design when deployed.

## Synthesis Review Questions

For every cross-module project, reviewers should ask:

1. What is the primary claim?
2. Which module provides the central method?
3. Which module provides the domain context?
4. Which module provides the ethical or institutional analysis?
5. Which module provides the communication or portfolio translation?
6. Are the modules genuinely integrated or merely listed?
7. Does each method fit the question?
8. Are assumptions explicit?
9. Is the final artifact coherent?
