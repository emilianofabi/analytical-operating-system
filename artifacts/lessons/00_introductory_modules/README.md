# Introductory Module Lesson 1 Artifacts

This directory contains orientation artifacts for AOS introductory Lesson 1 work.

Each Lesson 1 is a doorway into a module. These files are not full courses, do not prove mastery, and should not be treated as portfolio evidence while they remain drafts.

Each lesson must eventually pass through:

artifact -> review -> revision -> audit -> closure

Safe career claims require review and audit before they can be used as evidence. Draft lesson files should remain marked as not reviewed, not audited, and not closed until the full loop is complete.
